# Slidev - Clase 2: Machine Learning en Finanzas

Presentación sobre Machine Learning en Finanzas usando Slidev.

## Instalación

```bash
npm install
```

## Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

Esto abrirá la presentación en `http://localhost:3030`

## Exportar

Para exportar la presentación:

```bash
# Exportar como SPA (Single Page Application)
npm run export

# Exportar como PDF
npm run export-pdf

# Exportar como PNG
npm run export-png
```
