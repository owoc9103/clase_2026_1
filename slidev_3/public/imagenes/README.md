# Imágenes del libro (Cap. 1)

Coloque aquí **capturas de pantalla de las figuras del Capítulo 1** del libro *Machine Learning and Data Science Blueprints for Finance* (O'Reilly).

## Archivos que usa la presentación

| Archivo | Uso en las diapositivas |
|---------|-------------------------|
| `portada.jpg` | Portada del libro (slide "Referencia del libro" y "Referencia"). Si no existe, se usa una imagen externa. |
| `libro-ch01-landscape.png` | Figura del landscape / aplicaciones de ML en finanzas. |
| `libro-ch01-ai-ml-ds.png` | Diagrama relación AI / ML / Deep Learning / Data Science. |
| `libro-ch01-ml-types.png` | Diagrama tipos de ML (Supervised, Unsupervised, Reinforcement). |

Las diapositivas referencian estas rutas como `/imagenes/nombre.png`. Puede extraer las figuras del PDF del libro o hacer capturas del capítulo en O'Reilly.
