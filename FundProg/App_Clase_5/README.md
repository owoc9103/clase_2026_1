# Clase 5: Errores, Clases y Biblioteca Estándar

Aplicación interactiva en Streamlit para la Clase 5 de Fundamentos de Programación.

## Estructura

```
Clase_5/
├── main.py              # Página principal / Home
├── pages/
│   ├── 1_Errores_Excepciones.py
│   ├── 2_Clases_POO.py
│   ├── 3_Biblioteca_Estandar.py
│   ├── 4_Proyecto_Practico.py
│   └── 5_Editor_Validacion.py
├── utils/
│   ├── __init__.py
│   └── code_executor.py
├── requirements.txt
└── README.md
```

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
streamlit run main.py
```

La aplicación se abrirá en el navegador (por defecto http://localhost:8501).

## Contenido

- **Errores y Excepciones**: Teoría, preguntas y editor de código para try/except
- **Clases y POO**: Conceptos de POO, herencia, métodos especiales
- **Biblioteca Estándar**: math, datetime, statistics, os, pathlib
- **Proyecto Práctico**: Pasos del sistema bancario
- **Editor con Validación**: Ejecutar y validar código contra ejercicios
