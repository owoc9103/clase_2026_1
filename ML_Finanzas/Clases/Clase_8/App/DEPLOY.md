**Main file path para Streamlit Cloud:** `ML_Finanzas/Clases/Clase_7/App/main.py`

## Configuración en Streamlit Cloud

1. Conecta el repositorio `clase_2026_1`
2. **Main file path:** `ML_Finanzas/Clases/Clase_7/App/main.py`
3. **Python version:** 3.9 o superior
4. El `requirements.txt` está en la misma carpeta que `main.py`

## Dependencias

- streamlit
- pandas
- numpy
- scikit-learn
- plotly
